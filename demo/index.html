Portaldot forgets. Pindex remembers.

The public Portaldot V3 testnet node throws away old blocks within minutes. Pindex captures every event as it happens, flags anything it missed, and serves it as a REST API and a searchable app.

The problem

Builders on Portaldot who want to know who holds a token, who owns an NFT, or what a contract emitted have to write their own block scraper first. That is the first thing a dapp needs and the last thing a team wants to build.

It is harder on this testnet: the node keeps state for only a few hundred blocks, so anything not captured as it happens is gone for good.

What Pindex does

It reads the chain's own metadata and builds the database and API from it. A new pallet or event needs no new code. On the Portaldot testnet that produced 167 tables on its own.

It stores what it sees, records every range it could not capture, and layers a snapshot of chain storage underneath, so balances stay correct even for things that existed before it started.

How it works

  1. Reads the chain's metadataEvery pallet and event the runtime defines, with field names and types.
  2. Creates one typed table per eventFor example balances_transfer or nfts_issued, with real column types. No handlers to write.
  3. Follows finalized blocksEach block and its cursor are saved in one transaction. If the node has already discarded a range, the gap is recorded, not hidden.
  4. Serves it backA public read-only REST API and this app. GraphQL is available if you self-host.

What you can do today

  • Look up any address that has appeared on chain, by native (5...) or EVM (0x...) form: balances, NFTs and recent events.
  • See token holders ranked by balance, and who owns each NFT.
  • Browse the latest events from every indexed pallet, including staking and sessions.
  • Query the same data over REST with filters and pagination.
  • Contract event decoding with your own ABI in progress
  • Per-era staking history for validator tools planned

For developers

Read-only, open CORS, no key needed.

curl "https://portalindex-98f0.onrender.com/asset_balances?order=balance.desc"
curl "https://portalindex-98f0.onrender.com/events?pallet=eq.staking&limit=5"
curl "https://portalindex-98f0.onrender.com/indexer_gaps"

Token amounts are 128-bit integers and arrive as plain JSON numbers, so parse them as big integers.
